Nəzarət Paneli — аналитика по подрядчикам
Веб-приложение (FastAPI + PostgreSQL) для сравнения подрядчиков по расходам
на ремонт техники. Загружаете Excel-файл за очередной месяц — приложение
само раскладывает его по базе и обновляет графики.
Как это работает
Загрузка файла. Каждый лист файла = один подрядчик (имя листа = имя
подрядчика). Имя файла определяет период — например `August_2026.xlsx`
или `Avqust_2026.xlsx` распознаётся как август 2026. Также понимаются
форматы `2026-08.xlsx`, `08-2026.xlsx`.
Хранение. Вся строка таблицы переносится в PostgreSQL без потерь
(дата, описание работ, кол-во, цена, итог, исполнитель, участок, примечание
и т.д.). Если файл за уже загруженный период и подрядчика перезалить —
старые строки за этот период заменяются новыми (на случай исправлений).
Дашборд. Три (или больше — сколько листов в файле) панели, по одной
на подрядчика. У каждой — столбчатая диаграмма по типам техники (`NV növü`)
и список под ней с суммой по каждому типу.
Drill-down. Клик по типу техники (в списке или на графике) открывает
всплывающее окно со списком номеров техники (`DQ №-si`) этого типа и суммой
по каждому. Клик по конкретному номеру — открывает полную историю ремонта
этой единицы (дата, работа, кол-во, цена, итог, исполнитель, участок).
Период. Селектор сверху фильтрует всё (графики, списки, историю) по
выбранному месяцу или показывает данные за всё время накопления.
Запуск на Windows — без командной строки и без Docker
Ничего заранее устанавливать не нужно, кроме Python (один раз).
Установите Python: https://www.python.org/downloads/
При установке обязательно поставьте галочку "Add python.exe to PATH"
(это внизу первого экрана установщика).
Дважды кликните `start.bat`. В первый раз он сам:
создаст изолированное окружение (`.venv`),
установит нужные библиотеки,
создаст файл базы данных `data\contractors.db`,
откроет дашборд в браузере на `http://localhost:8000`.
Повторные запуски проходят за пару секунд.
Чтобы остановить — просто закройте открывшееся чёрное окно (сервер работает
в нём; закрытие окна = остановка). Все данные при этом остаются в
`data\contractors.db` и будут на месте при следующем запуске `start.bat`.
По умолчанию используется файловая база SQLite (`data\contractors.db`) —
это тоже полноценная реляционная БД, отдельный сервер для неё не нужен.
Если позже понадобится PostgreSQL (например, для сервера с несколькими
пользователями), достаточно задать переменную окружения `DATABASE_URL` — код
менять не нужно, приложение подхватит её автоматически (см. `.env.example`).
Запуск через Docker (опционально, для сервера с PostgreSQL)
Если Docker Desktop всё же есть или его поставят позже — в архиве остались
`start-docker.bat` / `stop-docker.bat`, которые поднимают приложение вместе
с PostgreSQL в контейнерах. Это удобно, если планируется общий сервер на
несколько человек, а не запуск на одном компьютере.
```bash
docker compose up --build
```
Приложение будет доступно на http://localhost:8000.
Запуск без Docker
Поднимите PostgreSQL и создайте базу/пользователя (см. `.env.example`).
Установите зависимости:
```bash
   pip install -r requirements.txt
   ```
Скопируйте `.env.example` в `.env` и укажите свою строку подключения,
либо экспортируйте `DATABASE_URL` перед запуском.
Запустите:
```bash
   uvicorn app.main:app --reload
   ```
Структура проекта
```
app/
  main.py          - точка входа FastAPI
  database.py       - подключение к PostgreSQL
  models.py         - таблицы: Contractor, Equipment, Upload, UploadSheet, RepairRecord
  parser.py         - разбор .xlsx (определение периода из имени файла, чтение листов)
  routers/
    upload.py       - POST /api/upload
    dashboard.py    - GET /api/periods, GET /api/dashboard
    equipment.py    - GET /api/equipment/{dq_number}/history
static/             - CSS + JS дашборда (тёмная тема)
templates/          - index.html
```
Важно про имена файлов
Если в имени файла не удаётся распознать месяц/год, загрузка вернёт понятную
ошибку с просьбой переименовать файл (например в `August_2026.xlsx`).
Название листа при этом всегда берётся как есть — это и есть имя подрядчика,
которое увидите на дашборде.
